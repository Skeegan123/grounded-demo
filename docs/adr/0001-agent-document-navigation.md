# External Agent document navigation is current-only and visibly applied

Grounded exposes `navigate_document` as a focused Document Browsing command: it accepts the identity of the currently accessible Project Document and an optional page, block, or region `target` describing one Document Destination, while `DocumentNavigator` resolves that destination without exposing historical document versions. A call succeeds only after the requested Document Destination is rendered and fitted without highlighting; a newer External Agent navigation or Senior Project Manager browsing action supersedes the pending navigation, and Assistance state remains untouched. This makes tool results describe the view a person can actually see while keeping version history and workflow automation outside the MVP.
